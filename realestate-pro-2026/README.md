# EstatePro — Real Estate Template (Beginner Friendly)

Professional, responsive real estate website with easy backend.

## Features (2026 trends)
- Hero search (location/type/price/beds)
- Featured + filterable listings (9 demo)
- Mortgage calculator (~6% demo)
- 3D tour placeholders, save/view buttons
- Agent profiles with ratings
- Contact form + map + mortgage calc
- Admin backend: edit config.js or use localStorage demo

## How to Configure (30 sec, no code)
1. Open `config.js` in Notepad / VS Code
2. Change `siteName`, `phone`, or add objects to `listings: [...]`
   Example: { price: 500000, beds: 2, baths: 1, area: 1000, type: "House", city: "Miami", img: "https://..." }
3. Save → Upload folder to GitHub Pages / Netlify (drag & drop) → Done

## Files
- index.html (Home), listings.html, agents.html, contact.html, admin.html
- config.js (edit me)
- All styling via Tailwind CDN (no build step)

## Deploy to GitHub Pages
1. Create repo -> Settings -> Pages -> Source: main branch / (root)
2. Upload these files to repo
3. Visit https://username.github.io/repo/
